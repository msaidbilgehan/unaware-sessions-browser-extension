# WebDAV UI 配置说明

## 核心配置项

### 连接配置

| 配置项 | 字段名 | 类型 | 默认值 | 说明 |
|--------|--------|------|--------|------|
| WebDAV 地址 | `webdavHost` | string | 空 | WebDAV 服务器地址，如 `http://localhost:8080` |
| 用户名 | `webdavUser` | string | 空 | WebDAV 认证用户名 |
| 密码 | `webdavPass` | string | 空 | WebDAV 认证密码 |
| 服务器路径 | `webdavPath` | string | `/backup` | WebDAV 服务器上的备份存储路径 |

### 同步策略配置

| 配置项 | 字段名 | 类型 | 默认值 | 说明 |
|--------|--------|------|--------|------|
| 同步间隔 | `webdavSyncInterval` | number | 0 | 自动同步时间间隔（分钟），0 表示关闭自动同步 |
| 最大备份数 | `webdavMaxBackups` | number | 0 | 保留的最大备份文件数量，0 表示无限制 |

### 高级选项

| 配置项 | 字段名 | 类型 | 默认值 | 说明 |
|--------|--------|------|--------|------|
| 跳过文件数据 | `webdavSkipBackupFile` | boolean | false | 是否跳过文件数据备份，仅备份配置和对话数据 |
| 禁用流式上传 | `webdavDisableStream` | boolean | false | 是否禁用流式上传，启用后将文件加载到内存后再上传 |

## UI 描述

### 主配置界面

**连接配置区域**
- WebDAV 地址输入框：支持 URL 格式输入，占位符显示 `http://localhost:8080`
- 用户名输入框：文本输入
- 密码输入框：密码类型输入
- 服务器路径输入框：占位符显示 `/backup`

**备份操作区域**
- 手动备份按钮：触发立即备份到 WebDAV
- 恢复按钮：打开备份文件管理器，支持从 WebDAV 恢复数据

**自动同步配置**
- 同步间隔选择器：下拉选择，支持以下选项
  - 关闭
  - 1 分钟、5 分钟、15 分钟、30 分钟
  - 1 小时、2 小时、6 小时、12 小时、24 小时
- 最大备份数量选择器：下拉选择，支持以下选项
  - 无限制
  - 1、3、5、10、20、50

**高级选项**
- 跳过文件数据开关：切换是否备份文件数据
- 禁用流式上传开关：切换上传方式，解决部分 WebDAV 服务器兼容性问题

**同步状态显示**
- 最后同步时间：显示格式为 `HH:mm:ss`
- 同步中状态：显示旋转图标
- 错误状态：显示错误提示图标和错误信息

### 备份文件管理器

**文件列表表格**
- 文件名列：显示备份文件名，支持截断显示和悬停查看完整名称
- 修改时间列：显示格式为 `YYYY-MM-DD HH:mm:ss`
- 大小列：显示文件大小，自动转换为可读格式（KB、MB 等）
- 操作列：每行提供恢复和删除按钮

**分页控制**
- 每页显示 5 条记录
- 显示当前页码和总页数
- 提供上一页和下一页导航按钮

**操作按钮**
- 刷新按钮：重新获取备份文件列表
- 批量删除按钮：删除选中的备份文件，显示选中数量

**确认对话框**
- 删除确认：单文件删除和批量删除分别显示不同的确认提示
- 恢复确认：提示恢复操作将覆盖当前数据
